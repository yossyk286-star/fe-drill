# FEドリル

基本情報技術者試験 科目A の一問一答ドリル。ビルド不要の静的サイト(HTML/CSS/JS)。

## できること
- 答えるときに自信(自信あり/たぶん/勘)を選ぶ。勘で当たった問題は正解でも翌日に出し直し、「たぶん」は3日以内に出す(成績タブで切替)
- 選択肢を隠して、問題文だけで答えを思い出してから選択肢を見る(成績タブで切替)
- 間違えた理由(知らなかった/勘違い/計算ミス/読み違い)を1タップで記録し、成績タブにミスの傾向
- 間違えた(勘で当たった)問題の次に、同じ分野で用語がよく重なる問題を1問差し込む
- 公式・覚え方まとめ(`formulas.js`)。用語タブの「公式」と、問題画面の公式ボタンから開く
- 用語カードの逆向き(意味 → 用語)
- 科目B：擬似言語のアルゴリズム問題(プログラム表示・解答後にトレース表)と情報セキュリティの事例問題
- 科目B 模擬試験：本番と同じ20問(アルゴリズム16・セキュリティ4)・100分
- 間隔をあけた自動復習：正解が続くと 1→3→7→14→30日後、間違えると翌日に「今日の復習」に出る
- 模擬試験は科目Aの公表されている目安の配分(テクノロジ41・マネジメント7・ストラテジ12)で60問
- 試験日を設定すると「試験まであと◯日」、1日の目標問数と達成状況
- 用語の暗記カード(タップでめくる・左右スワイプで覚えた/まだ)
- 学習記録のバックアップ(コピー/ファイル保存)と復元
- ホーム画面に追加するとアプリとして全画面で開ける。一度開けばオフラインでも使える(Vercel など https の公開先で有効)
- 今日解いた数・連続学習日数・直近7日間のグラフ
- 分野別に解く(テクノロジ・マネジメント・ストラテジの15分野から選択)
- ランダム10問
- 間違えた問題だけ解き直す(直近で不正解だった問題)
- チェックした問題を見直す
- 模擬試験(最大60問・90分タイマー、最後にまとめて採点)
- 2回連続正解で「習得済み」、習得済みを出題から外すオプション
- 分野別の正答率
- 用語の説明：問題文・選択肢・解説に出てくる用語に点線が付き、タップで意味が出る。解く前は問題の下の用語ボタンから確認できる。検索付きの用語集画面もある
- 学習記録はブラウザの localStorage に保存(キー: `fe-drill-v1`)
- キーボード: 1〜4 / a〜d で回答、Enter・→ で次へ

## 問題の追加
`questions-*.js` のどれかに同じ形式で足す(新しいファイルを作る場合は `index.html` と `build-artifact.py` にも追加)。オリジナル問題(`src: "オリジナル"`)は画面で選択肢の並びが毎回入れ替わるので、解説で「アは〜」のように記号で選択肢を指さないこと。IPA の過去問題は公式の並びのまま出る。

```js
{
  id: "r01a-01", cat: "基礎理論", src: "令和元年秋 午前 問1",
  q: "問題文", c: ["ア", "イ", "ウ", "エ"], a: 0,
  ex: "解説", why: ["アの補足", "イの補足", "ウの補足", "エの補足"],
}
```

- `cat` は `CATEGORIES` にある分野名のどれか
- `a` は正解の位置(ア=0, イ=1, ウ=2, エ=3)
- IPA の過去問題を使うときは `src` に出典(年度・期・問番号)を必ず書く
- 他サイト(過去問道場など)の解説文はコピーしない。解説は自分で書く

## 用語の追加
`glossary.js` の `GLOSSARY` に足すと、全問題の本文に自動で反映される。

```js
{ t: "用語", r: "よみ(任意)", al: ["略称", "別名"], d: "説明" }
```

- 長い用語が優先して一致する(「公開鍵暗号方式」は「公開鍵」より先)
- 短い英字の略称は別の単語の一部に一致しないか確認する(例：RACI の中の CI)
